TEST 2: CACHE HIT/MISS VERIFICATION
============================================================

Objective:
To verify that the HTTP forward proxy caches eligible responses and reuses them for repeated requests.

Procedure:
Sent repeated GET requests to http://httpbin.org/get through the proxy at 127.0.0.1:8080.

Command:
curl.exe -i -x http://127.0.0.1:8080 http://httpbin.org/get

Results:
- The initial request produced a cache MISS and fetched the response from the origin server.
- The response was saved in the proxy cache.
- A subsequent request produced a cache HIT and returned the cached response with HTTP status 200.
- The response time recorded in the report text supplied later was 2.672 seconds for the MISS and 0.030 seconds for the HIT.

Additional cache timing evidence from a separate example.com run:
Command:
curl.exe -s -o NUL -w "Time: %{time_total}s`n" -x http://127.0.0.1:8080 http://example.com/

First request output:
Time: 0.228781s

Second request output:
Time: 0.022731s

Relevant proxy log entries:
2026-10-11 00:20:16 ... CACHE EXPIRED
CACHE MISS: http://example.com/
... Connected to destination example.com:80
... Response saved to cache
... Status: 200 | Cache: MISS | Time: 0.227s

2026-10-11 00:20:31 ... CACHE HIT: http://example.com/
... Status: 200 | Cache: HIT | Time: 0.021s

Conclusion:
The test passed. The proxy successfully cached and reused an eligible HTTP response, reducing response time for the tested request.

Note:
The httpbin.org timing and example.com timing are separate recorded runs; they should not be mixed as if they came from one test run. In a later attempt, httpbin.org failed DNS resolution, so that failed attempt is not used as evidence of the successful cache test.
